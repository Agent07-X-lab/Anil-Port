# **App Name**: Neon Codex

## Core Features:

- Animated Hero Section: Full-screen hero section with a dynamic particle network background and a spotlight effect that highlights the developer's name and roles.
- Interactive Ballpit About Me Section: An 'About Me' section featuring an interactive Ballpit component built with Three.js to provide a visually engaging background.
- Animated Skills Grid: Interactive grid showcasing the developer's skills with animated progress bars, proficiency levels, and flip animations to display project counts using each skill.
- Project Showcase Grid: Glassmorphic card-based grid to display featured projects, including project screenshots, tech stack badges, and descriptions.
- AI-Powered Chatbot Integration: Showcase an AI-powered chatbot, utilizing React, Node.js, and the OpenAI GPT API to simulate context-aware human conversations.
- Experience Timeline: Vertical timeline displaying the developer's education, certifications, and achievements using animated elements.
- Interactive Contact Form: Interactive contact form with animated elements and validation to facilitate user engagement and feedback.

## Style Guidelines:

- Background: Deep Space Black (#0a0a0a) provides a stark, immersive backdrop that emphasizes the bright, neon accents. This choice is inspired by the futuristic, cyberpunk aesthetic.
- Primary Accent: Electric Cyan (#00f5ff) creates vibrant highlights and draws attention to interactive elements and key information. The color creates a jolt of electricity.
- Secondary Color: Vibrant Purple (#a855f7) provides a lush counterpoint to the cyan. The purple evokes the drama of digital world-building and high technology.
- Headers: 'Space Grotesk', a sans-serif font, gives a bold, futuristic aesthetic appropriate for the tech focus of the portfolio.
- Body: 'Inter', a grotesque-style sans-serif font, ensures readability while maintaining a modern and neutral appearance.
- Code blocks: 'Source Code Pro', a monospaced font, ensures that the code is readable in the portfolio.
- Parallax scrolling to create a sense of depth and immersion as the user navigates through the portfolio.
- Mouse-following gradient spotlight to highlight specific areas of the screen.
